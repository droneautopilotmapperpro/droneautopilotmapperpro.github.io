// 03. FIGHTER HUD COCKPIT & 6 TACTICAL TABS

01 // SETUP — Flight Setup

Pilih preset 39 drone pemetaan, unduh peta offline, atur Altitude, Speed, Gimbal Tilt, Overlap, Endpoints-only, Calculate Plan, Force H (E-W), ekspor KML/KMZ/Share, dan pantau Mission Output Summary.

Select from 39 proven mapping drone presets, download offline tiles, configure Altitude, Speed, Gimbal Tilt, Overlap, Endpoints-only, Calculate Plan, Force H (E-W), export KML/KMZ/Share, and inspect live Mission Summary.

02 // CAM — Camera & Grid

Atur manual Sensor Width, Focal Length, Resolution, centang True lawn-mower (boustrophedon) + 4 arah sudut start, interval foto, foto tiap waypoint, dan opsi Include RTH.

Override Sensor Width, Focal Length, Resolution, toggle True lawn-mower (boustrophedon) + 4 start corners, photo interval, photo at each waypoint, and Include RTH.

03 // DEM — Terrain Follow

Muat file GeoTIFF DEM (.tif), tampilkan overlay elevasi di peta, atur ketinggian AGL konstan mengikuti kontur bukit/lembah, vertical offset, atau bypass sementara.

Load GeoTIFF DEM (.tif), preview heatmap overlay on the map, maintain constant AGL across hills/valleys, apply vertical offset, or force fixed altitude override.

04 // STA — Corridor STA Tool

Hitung stasiun koridor jalan/tol (STA KM+m), kecepatan, dan altitude pada file .srt DJI, lalu mux langsung ke MP4 atau ekstrak subtitle tertanam.

Compute highway/corridor stationing (STA KM+m), ground speed, and altitude inside DJI .srt logs, mux directly into MP4, or extract embedded subtitle tracks.

05 // SDK — DJI MSDK Flight

Registrasi DJI App Key, buka layar FPV live, jalankan misi Onboard KMZ / Virtual Stick / Share KMZ, kontrol Start-Pause-Resume-Stop, Takeoff/Land/RTH, dan trigger kamera/gimbal.

Register DJI App Key, toggle live FPV feed, run Onboard KMZ / Virtual Stick / Share KMZ flights, control Start-Pause-Resume-Stop, Takeoff/Land/RTH, and camera/gimbal actions.

06 // NEWS — Dispatch Feed

Portal berita & modul web interaktif langsung di dalam aplikasi (mendukung scroll penuh, zoom jari, tombol kembali, musik latar, serta cache offline otomatis).

Live interactive web manual & release news right inside the app (supports full smooth touch scrolling, pinch zoom, back navigation, BGM playback, and automatic offline caching).

// 04. MISSION PLANNING, LAWNMOWER 4-DIR & GIMBAL WPT-1 FLOW

1
Muat Peta & Overlay Referensi Sipil (Opsional)Open Base Map & Load Civil Reference Overlay (Optional)

Klik tombol OPEN di HUD atas atau Overlay di dock bawah untuk membuka file .kml, .kmz (seperti CL STA / ROW Tol), .dxf (pilih CRS UTM/TM-3/lokal), .geojson, atau shapefile .zip sebagai penunjuk batas survei. Gunakan ⚙ Layers di kanan atas untuk mengganti peta Satelit Esri, Google, OSM, Topo, atau Offline map cache.

Tap OPEN on the top HUD or Overlay on the bottom dock to display reference .kml, .kmz (centerline/ROW), .dxf (with UTM/TM-3 CRS reprojection), .geojson, or zipped Shapefiles. Use top-right ⚙ Layers to switch between Esri Hybrid, Google Satellite/Road, OSM, OpenTopo, or Offline map cache.

2
Gambar Area Survei (AOI) atau Koridor / Import PolygonDraw Survey Polygon / Corridor Line or Import Polygon

Gunakan toolbar gambar Leaflet di sisi kanan peta (Polygon untuk pemetaan area luas, atau Polyline untuk survei koridor jalan/sungai), atau klik Import Polygon di tab SETUP untuk mengambil AOI dari KML/DXF/GeoJSON. Gunakan ikon pensil untuk edit vertex atau Clear untuk mengulang.

Use the right-hand Leaflet drawing tools (Polygon for area grids, or Polyline for linear road/river corridors), or tap Import Polygon inside SETUP to import AOI geometry from KML/DXF/GeoJSON. Edit vertices anytime with Undo/Redo support.

3
Pilih Drone, Parameter Terbang, Gimbal & Arah LawnmowerSelect Drone Preset, Altitude, Gimbal Mode & Lawnmower Direction

Pilih drone Anda di tab SETUP. Isi Altitude (m), Speed (m/s), Front Overlap (%), Side Overlap (%). Di mode Gimbal Tilt: pilih 2D (Nadir) (-90°), 3D (Oblique -45°), atau Manual Custom (mis. -45 atau sudut miring lainnya). Pada V.9.2, perintah gimbal ditempatkan khusus di Waypoint #1 (WPT 0) sehingga drone langsung mengunci sudut gimbal sebelum mulai memotret tanpa jeda ulang di waypoint berikutnya.

Pick your aircraft in SETUP. Set Altitude (m), Speed (m/s), Front Overlap (%), and Side Overlap (%). Choose Gimbal Tilt: 2D (Nadir) (-90°), 3D (Oblique -45°), or Manual Custom (e.g. -45°). In V.9.2, the gimbal pitch command is injected once cleanly at Waypoint #1 (WPT 0) before the first shutter trigger.

4
Klik Calculate Plan / Force H (E-W) & Atur di PetaTap Calculate Plan / Force H (E-W) & Fine-Tune on Map

Tekan Calculate Plan (otomatis memilih sumbu terhemat baterai, atau mengikuti arah N-S dengan sudut start pilihan Anda jika True lawn-mower dicentang di tab CAM), atau tekan Force H (E–W) untuk jalur lurus Timur–Barat. Anda dapat menggeser misi dengan handle cyan (⌖ Move) atau memutar misi dengan handle emas (↻ Rotate), lalu periksa hasil estimasi waktu & kebutuhan baterai di Mission Output / Summary.

Tap Calculate Plan (optimal axis, or N-S boustrophedon from your chosen start corner when True lawn-mower is enabled in CAM) or Force H (E–W) for pure East-West parallel tracks. Drag the cyan handle (⌖ Move) or gold handle (↻ Rotate) directly on the map and verify flight duration & battery estimates inside Mission Output / Summary.

  • Peta Satelit Offline (Tab SETUP): Arahkan viewport peta ke area proyek saat masih ada internet, lalu klik Download map for offline use (maks. 2.500 tile). Saat di lapangan tanpa sinyal, buka ⚙ Layers > Base Map > Offline map cache.
  • Terrain Follow (Tab DEM): Tekan Load DEM (GeoTIFF .tif SRTM/DSM WGS84 atau UTM). Klik Show DEM untuk overlay warna ketinggian, atur AGL & DEM vertical offset (selisih elevasi tanah di titik Home agar konversi ke ketinggian relatif drone akurat), lalu klik Apply DEM to WPTs.
  • Jika proyek membutuhkan ketinggian datar (bypass DEM sementara), centang Force altitude override (ignore DEM).
English
  • Offline Satellite Cache (SETUP Tab): Pan/zoom the map to your project site while online, then tap Download map for offline use (up to 2,500 tiles). In the field, switch Base Map in ⚙ Layers to Offline map cache.
  • DEM Terrain Follow (DEM Tab): Tap Load DEM (GeoTIFF .tif in WGS84 or UTM). Use Show DEM to visualize terrain, enter AGL & DEM vertical offset (Home point terrain elevation for accurate AGL-to-relative altitude conversion), then tap Apply DEM to WPTs.
  • Check Force altitude override (ignore DEM) whenever you need a flat mission altitude without unloading the GeoTIFF.

// 07. STA CORRIDOR SUBTITLE GENERATOR & MP4 TOOL

Bahasa Indonesia
  1. Buka tab STA. Aktifkan video subtitle/captions di pengaturan kamera DJI agar drone merekam file .srt atau track subtitle MP4.
  2. Pilih file .srt (Browse...), atau pilih video .mp4 terlebih dahulu lalu klik Extract embedded SRT jika drone menyimpan telemetry di dalam MP4.
  3. Klik ⌖ Pick di dock bawah peta untuk mengetuk titik STA awal pada overlay Centerline (CL), lalu isi Starting STA (km) & Starting meter (mendukung offset negatif).
  4. Klik Create STA Text untuk mengekspor *_with_STA.srt, atau Mix video with .srt untuk menanamkan subtitle STA ke dalam file .mp4 secara offline di Android tanpa server eksternal.
English
  1. Open the STA tab. Ensure video captions/telemetry logging is enabled in DJI camera settings during corridor flights.
  2. Select your .srt telemetry file, or pick an .mp4 video and tap Extract embedded SRT when telemetry is muxed inside the video stream.
  3. Tap ⌖ Pick on the map dock to tap your starting centerline point, then verify Starting STA (km) & Starting meter (negative initial offsets supported).
  4. Tap Create STA Text to export *_with_STA.srt, or Mix video with .srt to mux formatted STA overlays cleanly into an MP4 completely offline on-device.

SKILL 01 TAB: CAM & SETUP

3D Double-Grid (Crosshatch +90°)3D Double-Grid Crosshatch (+90°)

Menghasilkan dua grid tegak lurus otomatis untuk pemodelan 3D bangunan, lereng tambang & stockpile. Pass ke-2 menyambung ke titik ujung terdekat agar hemat baterai, plus tombol cepat -60° Oblique Gimbal. Generates dual orthogonal passes for crisp 3D building, quarry & stockpile meshes. Pass 2 connects cleanly from the nearest endpoint, with a 1-tap -60° Oblique Gimbal shortcut.
Buka tab CAM → centang 3D Double-Grid Crosshatch → ketuk Set -60° Oblique Gimbal → tekan Calculate Plan. Open CAM → enable 3D Double-Grid Crosshatch → tap Set -60° Oblique Gimbal → press Calculate Plan.
SKILL 02 TAB: SETUP & SDK

Smart Multi-Battery Split & Resume WPTSmart Multi-Battery Split & Resume WPT

Membagi misi besar menjadi leg B1, B2..BN sesuai reserve RTH (10–50%), overlap 1 WPT per batas leg, serta batas ≤ 99 WPT otomatis di MSDK V4 dan kontrol Resume WPT #. Splits large missions into B1..BN legs respecting RTH reserve (10–50%), 1-WPT continuity overlap, automatic ≤ 99 WPT cap on MSDK V4 and manual Resume WPT # slicing.
Setelah Calculate Plan, pilih chip B1 / B2 atau isi Resume WPT # di tab SETUP/SDK — tombol Upload/Share KMZ otomatis mengirim leg aktif saja. After Calculate Plan, tap B1/B2 chips or set Resume WPT # in SETUP/SDK — Upload/Share KMZ runs only that battery slice.
SKILL 03 TAB: CAM

Target GSD Solver & Motion-Blur GuardTarget GSD Solver & Motion-Blur Guard

Ketuk target GSD (1.0–5.0 cm/px) untuk menghitung ketinggian tepat sesuai sensor drone, lalu pantau risiko foto buram terhadap Shutter Speed (1/125s–1/2000s) dengan tombol Apply Safe Speed. Tap a target GSD (1.0–5.0 cm/px) to solve exact flight altitude, then monitor frame smear against Shutter Speed (1/125s–1/2000s) with 1-tap Apply Safe Speed.
Di tab CAM → pilih pill 1.5cm / 2.0cm → cek badge SHARP → tekan Safe Speed jika muncul peringatan blur kuning/merah. In CAM → tap a GSD pill → confirm green SHARP badge → tap Safe Speed whenever caution/severe blur appears.
SKILL 04 TAB: CAM

Smart Flight-Angle Auto-Optimizer (0°–180°)Smart Flight-Angle Auto-Optimizer (0°–180°)

Menyapu sudut azimut grid setiap 5° pada poligon miring untuk mencari sudut belokan paling sedikit dan waktu paling singkat (termasuk vektor angin), plus input manual sudut kustom 0°–180°. Sweeps grid azimuth in 5° increments on skewed AOIs to minimize turns and wind-adjusted time, plus supports exact numeric 0°–180° manual angle input.
Gambar poligon miring di peta → buka tab CAM → tekan Optimize Angle ⚡ → rute otomatis terhitung ulang di sudut terbaik. Draw an angled AOI polygon → open CAM → tap Optimize Angle ⚡ → grid recalculates at the fastest azimuth.
SKILL 05 TAB: DEM

Grafik Profil Elevasi 2D & Clearance Terrain2D Mission Elevation & Terrain Clearance Chart

Grafik Canvas langsung di tab DEM menampilkan kurva elevasi tanah vs lintasan terbang, garis aman AGL, nilai MIN AGL, puncak bukit, total climb dan kemiringan tanjakan maksimum. Real-time Canvas chart in DEM plotting ground terrain vs aircraft path, dashed safety AGL floor, MIN AGL, peak ground elevation, total climb and max slope angle.
Buka tab DEM setelah Apply DEM to WPTs; titik merah di kurva menandakan waypoint dengan jarak aman < 20 m dari permukaan bukit. Open DEM after Apply DEM to WPTs; red dots mark any waypoint dropping below 20 m AGL threshold.
SKILL 06 TAB: SETUP (PRO TOOLS)

No-Fly Zone (NFZ) Keep-Out & Auto-CarveNo-Fly Zone (NFZ) Keep-Out Cutout & Audit

Tambahkan zona larangan rintangan (SUTET, tower, crane) via radius peta atau poligon gambar. Engine memotong lubang NFZ dari jalur grid tanpa zigzag berlebih & membunyikan blokir jika ada WPT masuk NFZ. Define obstacle keep-out zones (towers, cranes, no-fly compounds) from map center or drawn polygons. JTS geometry carves clean NFZ holes and blocks upload on breaches.
Tab SETUP → Pro Tools > NFZ → atur Radius + Buffer → tekan + Circle @ Map Center lalu Calculate Plan ulang. SETUP → Pro Tools > NFZ → set Radius + Buffer → tap + Circle @ Map Center then re-run Calculate Plan.
SKILL 07 TAB: SETUP (3D ORBIT)

3D Orbit Helikal & Inspeksi POI Menara3D Helical Orbit & Tower POI Inspector

Buat misi orbit melingkar atau spiral naik (helical) multi-cincin mengelilingi objek/tower dengan hidung drone selalu mengarah ke pusat POI (Toward POI WPML) dan gimbal tilt terhitung otomatis. Generates multi-ring circular or helical climbs around towers/assets with aircraft nose locked inward (Toward POI in WPML) and automatic oblique gimbal angle calculation.
Pusatkan peta pada gedung/menara → tab SETUP → Pro Tools > 3D ORBIT → tekan Set @ Map Center → klik Generate 3D Orbit Mission. Center map on tower/asset → SETUP → Pro Tools > 3D ORBIT → tap Set @ Map Center → hit Generate 3D Orbit Mission.
SKILL 08 TAB: SETUP (WIND SIM)

Bahasa Indonesia

English
  • Offline Satellite Cache (SETUP Tab): Pan/zoom the map to your project site while online, then tap Download map for offline use (up to 2,500 tiles). In the field, switch Base Map in ⚙ Layers to Offline map cache.
